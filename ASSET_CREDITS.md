# Фотографии и постеры MovieMind

## Постеры фильмов
Постеры не хранятся в репозитории: сайт подгружает их по ссылкам с Яндекс.Аватаров Кинопоиска (`avatars.mds.yandex.net/get-kinopoisk-image/...`). Права на постеры принадлежат правообладателям фильмов; данные и ссылки взяты со списка [500 лучших фильмов — Кинопоиск](https://www.kinopoisk.ru/lists/movies/top500/) для учебного проекта.
