# MovieMind

Учебный сайт для выбора фильма по настроению. Статический HTML/CSS/JavaScript, без сборки, ключей API и сторонних библиотек.

### Что сделано

- Переработан дизайн всех пяти страниц: главная, каталог, подбор, рекомендации, «Посмотреть позже». Киножурнальная композиция, тёмный сине-зелёный фон, тёплый акцент, крупные заголовки, светлый блок настроений.
- Добавлены 12 фотографических обложек с Unsplash / Pexels и фотография маяка для главного экрана. Фотографии загружены локально, проверены и оптимизированы; внешних запросов к фотостокам при открытии сайта нет. Это тематические обложки вымышленных фильмов, а не официальные постеры. Источники и лицензии — в ASSET_CREDITS.md.
- Добавлены окно с описанием фильма и случайный выбор; афиши и названия открывают описание.
- Добавлены переходы из трёх подборок по настроению в каталог с установленными фильтрами.
- Реализованы поиск по названию (регистр и «ё/е» не мешают), фильтрация по жанрам, годам, рейтингу и настроению, сортировка по рейтингу/году/названию, сброс фильтров.
- Вместо заранее заданных процентов реализована оценка совпадения: `S = 100 × (0.6 × G + 0.3 × R + 0.1 × Y)`. G — доля выбранных жанров, присутствующих у фильма; R — рейтинг / 10 (0 при отсутствии); Y — попадание в годы (1/0). Все ограничения, включая настроение, сначала применяются как фильтры. Несколько жанров при отборе работают через «ИЛИ», а большее покрытие повышает оценку. Результат — до 10 записей.
- Сохранён список «Посмотреть позже» в localStorage; добавлены состояния кнопок и уведомления.
- Добавлены мобильная вёрстка, фокус с клавиатуры, ссылка пропуска меню, подписи кнопок и состояний фильтров.
- Явно отмечены вымышленные фильмы, демо-рейтинги и тестовые сведения о доступности. Никакая реальная доступность фильмов не подтверждается.

## Запуск

Откройте `index.html` в браузере. Для одинакового поведения localStorage на всех страницах лучше запустить локальный сервер из папки проекта:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`. Сборка и установка пакетов не требуются.

## Структура

- `index.html`, `catalog.html`, `picker.html`, `recommendations.html`, `later.html` — страницы.
- `style.css` — единая тема и адаптивная вёрстка.
- `func.js` — интерфейс, фильтры, подбор, localStorage, диалоги.
- `data/movies.js` — текущие 12 демонстрационных записей.
- `data/availability.js` — тестовые источники просмотра.
- `assets/` — фотографии JPEG и favicon SVG.
- [NEXT_TASK.md](NEXT_TASK.md) — ТЗ следующему участнику с критериями приёмки.

## Ограничения текущего этапа

База демонстрационная, аккаунтов и сервера нет. Список сохраняется только в этом браузере. Настроение — ручной тег, оценка совпадения — простая формула, а не машинное обучение. Большая база и реальные источники просмотра — следующий этап.
