# MovieMind

Сайт для подбора фильма по настроению.

**Сделано в ветке yarik:** обновлён дизайн всех страниц, добавлены фотографии, описание фильма и случайный выбор. Работают поиск, фильтры, рекомендации и список «Посмотреть позже». Пока в базе 12 вымышленных фильмов.

## ТЗ для следующего

1. Взять готовые файлы из ветки **yarik** и продолжить в своей ветке.
2. Добавить **500–1000 реальных фильмов**: название, год, жанры, рейтинг, описание, настроение и настоящий постер. Неизвестные данные не выдумывать.
3. Заменить тестовые ссылки на проверенные страницы фильмов на сервисах просмотра.
4. Сохранить текущий дизайн. Проверить поиск, фильтры, подбор и список «Посмотреть позже» на компьютере и телефоне.
5. Загрузить результат в свою ветку, кратко написать в README, что сделано, и оставить ТЗ следующему.

Запуск: открыть `index.html`. [Источники фотографий](ASSET_CREDITS.md).
