# MovieMind

Сайт для подбора фильма по настроению. Запуск: открыть `index.html`. [Источники фотографий и постеров](ASSET_CREDITS.md).

**Сделано в ветке yarik:** обновлён дизайн всех страниц, добавлены фотографии, описание фильма и случайный выбор. Работают поиск, фильтры, рекомендации и список «Посмотреть позже». Была база из 12 вымышленных фильмов.

**Сделано в ветке David:**
- Вымышленные фильмы заменены на **494 реальных фильма** из списка «500 лучших фильмов» Кинопоиска (список снят 19.11.2026; до 500 не хватило 6 позиций: пока я собирал страницы, список на сайте сдвигался).
- Для каждого фильма: название, год, **один основной жанр**, рейтинг Кинопоиска, постер (ссылка на Яндекс.Аватары Кинопоиска, картинки не скачаны).
- **Настроение (`mood`) — не данные Кинопоиска**, а оценка по основному жанру: комедия 9; мюзикл, мультфильм, семейный 8; приключения, фэнтези 7; фантастика, аниме, спорт, боевик 6; мелодрама, биография, история, детектив, вестерн 5; драма, криминал 4; триллер, военный 3; ужасы 2.
- **Описаний нет:** в списке Кинопоиска их нет, выдумывать нельзя, сайт показывает «нет данных».
- Ссылки (`data/availability.js`): у 62 фильмов прямая ссылка на «Кинопоиск HD» (была кнопка «Смотреть»), у всех 494 — страница фильма на Кинопоиске. Другие сервисы (Иви, Okko, Wink и т.д.) **не проверялись**.
- Дизайн сохранён. Изменены тексты («демо» убрано), главный экран больше не рекламирует вымышленный фильм (кнопка ведёт на подбор), добавлен запасной вариант загрузки постера. Неиспользуемые фото из assets удалены, осталось `photo-1.jpg`.
- Логика поиска, фильтров, подбора и «Посмотреть позже» проверена в Node на новых данных; в браузере и на телефоне вручную не открывалась.

## ТЗ для следующего

1. Заполнить `description` (поле в `data/movies.js`) из страниц фильмов на Кинопоиске: только реальный текст, без выдумок.
2. Добавить недостающие жанры (у каждого фильма пока один) и заменить оценку `mood` на обоснованную.
3. Проверить и добавить ссылки на другие сервисы просмотра в `data/availability.js` (с датой проверки).
